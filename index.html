Clipped Daily Uploader

A private upload tool for the YouTube channel Clipped Daily.

Clipped Daily Uploader is a small command-line script used only by the owner of the Clipped Daily channel. It uses the YouTube Data API (YouTube API Services) to upload finished short videos from the owner's own computer to the owner's own channel and to schedule when they are published (title, description, category, audience setting and publish time).

It is not a public service: there are no other users, no sign-up, and no data from other YouTube users is collected. The owner signs in once with Google OAuth; the access token stays on the owner's computer.

Privacy Policy

Last updated: 18 October 2026

Clipped Daily Uploader ("the tool") is a personal command-line script used only by the owner of the YouTube channel Clipped Daily to upload and schedule that channel's own videos. This policy explains what data the tool handles.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • An OAuth access/refresh token for the signed-in Google account, with the scopes youtube.upload (upload videos) and youtube.readonly (confirm the channel name and the status of uploaded videos).
  • The channel's own channel ID and name, and the IDs, titles and publish times of videos the tool uploads.

The tool does not access, collect or store any data about other YouTube users, viewers, comments or analytics.

How data is used, stored and shared

  • Data is used only to upload the owner's videos and set their metadata and publish time.
  • The OAuth token and a local log of uploaded video IDs are stored only on the owner's own computer. Nothing is stored on any server operated by the tool.
  • No data is sold, shared with or disclosed to any third party, and no cookies or tracking are used.

Deleting data and revoking access

Access can be revoked at any time at Google security settings – third-party access. Deleting the local token file removes all stored credentials. Stored data is deleted on request or within 30 days of access being revoked.
